# URLラベルマップ

気になったURLにラベル(複数可)を付けてストックし、マインドマップで眺める静的サイトです。データは利用者自身のGoogle Driveのアプリ専用領域(appDataFolder)に保存します。自前のDB・サーバーはありません。

- 構成: 素のHTML・JS・CSS(ビルドなし)

## ローカルで動かす

`main.js` の `GOOGLE_CLIENT_ID` が空の間は「ローカル試用モード」になり、Googleにログインせず、データはブラウザの localStorage にだけ保存されます。画面にもその旨が出ます。

```bash
python -m http.server 8000
```

`http://localhost:8000/` を開きます。

## Googleログインを有効にする手順(動かす人が1回だけ行う)

Google Cloud の設定は、アプリを動かす人が1回だけ行います。利用者に必要な操作は、「Googleでログイン」を押してアプリ専用領域を許可することだけです。

1. Google Cloud Console でプロジェクトを作り、「Google Drive API」を有効にする。
2. 「OAuth同意画面」を設定し、スコープに `.../auth/drive.appdata` を追加する(審査不要の non-sensitive スコープ)。
   - **自分用(作者の運用)**: 公開ステータスは「テスト」のままにし、テストユーザーに自分のGoogleアカウントを追加する。必須入力はアプリ名・ユーザーサポートメール・デベロッパーの連絡先メールのみ。ホームページ・プライバシーポリシーURLは不要。
   - **他の人にも使わせる場合**: 公開ステータスを「本番環境」にする。必須入力に加えて、ホームページURL(公開先のURL)とプライバシーポリシーURL(公開先の `privacy.html`。運営者向けの雛形として使ってください。連絡先などは自分用に書き換える)が必要。ロゴは入れない(入れると検証が必要になる)。承認済みドメインは Console の指示に従う。
3. 「認証情報」で OAuth クライアントID(種類: ウェブ アプリケーション)を作り、承認済みの JavaScript 生成元に公開先のオリジン(例: `https://<ユーザー名>.github.io`、開発用に `http://localhost:8000`)を登録する。
4. 発行されたクライアントID(秘密情報ではありません。クライアントシークレットは使わないので、どこにも保存しない)を `main.js` の `GOOGLE_CLIENT_ID` に設定する。

## 一括登録(PCのみ)

「登録」パネルの「ファイルから一括登録」から、CSVまたはJSONをまとめて取り込めます(スマホ・タブレットのタッチ操作では表示されません)。ファイルはブラウザ内で読むだけで、どこにも送信しません。

- **CSV**: 1行に1件で、`URL,ラベル1,ラベル2,…` の形式です。1行目の先頭の列に `://` がなければ、ヘッダー行として読み飛ばします。ダブルクォートで囲んだ項目に対応します。文字コードはUTF-8(BOMあり・なし)とShift_JIS(ExcelのCSV(コンマ区切り))を自動で判別します。
- **JSON**: このアプリの「JSON保存」と同じ形(`{"urls":[{"url":"…","title":"…","labels":["…"]}]}`)、または `[{"url":"…","labels":["…"]}]` の配列です。
- すでにあるURLは、ラベルを足し合わせます(1URLにつき10個まで。上書き・削除はしません)。既存のタイトルは残します。同じファイルを2回取り込んでも、重複は増えません。
- 1ファイル1MB、1000件までです。URL形式やラベルが不正な行は取り込まず、「N行目: 理由」を最大5件まで表示します。
- タイトルは、取り込み後に背景で、同時に最大3件ずつ取得します(取れないURLはURL表示のままです)。
- 取り消しはできません。取り込み前に「JSON保存」しておくと、元の状態を残せます。

## タイトルを付ける(PC)

ブラウザから直接ページを取りに行く方法は、CORSで拒否されるサイトが多く、タイトルが付かないことがあります。PCのローカルで取りに行くスクリプト `tools/fill_titles.py` を使うと、まとめてタイトルを付けられます(Python 3 の標準ライブラリだけで動きます)。

```bash
python tools/fill_titles.py 入力ファイル
```

1. アプリの「保存」→「JSON保存」で、今のデータを保存する(または、一括登録と同じ形のCSVを用意する)。
2. 上のコマンドを実行する。タイトルが空のURLだけを、同時に3件ずつ取りに行く(1件10秒まで)。タイトルが付いたJSON(`入力ファイル名.titled.json`)が出力され、取れなかったURLと理由が一覧で出る。
3. アプリの「ファイルから一括登録」で、その JSON を取り込む。すでにあるURLでタイトルが空のものにだけタイトルが入り、ラベルは変わらない(足し合わせるだけ)。

- すでにタイトルがあるものは、取りに行かず、そのまま残す。
- ボット対策のあるサイト、JavaScriptで描画するページ、ログインが必要なページは、取れないことがある(タイトル空のまま残る)。
- 文字コードは、UTF-8、Shift_JIS、EUC-JP を判定する。`<title>` が空のときは `og:title` を使う。
- テスト: `python -m unittest discover -s tools`
## 既知の制約

- ログインのアクセストークンは約1時間で切れます(静的サイトではリフレッシュトークンを使えないため)。リロード時は、トークンが有効ならそのタブの sessionStorage から復帰し、切れていれば画面なしの再ログイン(`prompt: 'none'`)を試します。ブラウザにポップアップを止められた場合などは、ログインボタンが出ます。トークンが切れた状態で保存すると「再ログインして保存」の表示が出ます(未保存の変更は画面に保持)。
- 複数端末で同時に編集した場合は、後から保存した方が勝ちます。
- ページタイトルはブラウザからの直接fetchで取るため、CORSで拒否するサイトはURL表示になります(「タイトルを付ける(PC)」で、あとからまとめて付けられます)。
- ラベルを一度にたくさん開くと、URLの文字が重なることがあります。
